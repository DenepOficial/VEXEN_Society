# VEXEN Society v1.5

- La bienvenida usa la mención real del asociado (`<@USER_ID>`) en lugar del nombre manual.
- El botón de bienvenida y el CTA de anuncios muestran `Unirme a {COMUNIDAD}`.
- Los botones dejan de usar el emoji para verse más discretos.
- Estilo predeterminado: `secondary` (gris / oscuro).
- Nuevo comando `/society config estilo_boton_comunidad`.
- Opciones Discord: `primary — Azul`, `secondary — Gris / oscuro`, `success — Verde`, `danger — Rojo`.
- El comando intenta actualizar en vivo botones ya publicados.
- `/society config estado` muestra el estilo activo.
- `/society help` incluye el nuevo comando.
